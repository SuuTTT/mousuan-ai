# MouSuanAI v0.9.0

发布日期：2026-08-08

发布主题：Four Questions and the 1 + 3 + 1 + 5 Framework

## 版本定位

`v0.9.0` 是正式域名上线前的里程碑版本。它把 18 页内部结构手稿中的知识设计，与原有研究模块统一为面向研究者的分层网站；手稿本身不作为公开内容。

## 主要内容

- 以四个科学问题引入人工智能的数学基础、实质、策略和实现模型。
- 形成“信息中心—三个定义—孙子模型—五大模块”的 `1 + 3 + 1 + 5` 结构。
- 明确智能论题“智能 = 信息”、智能的策略原理“智能 = 谋算”和表示定律“智能 = 智 + 能”。
- 将每个主题、概念和模块拆分为独立页面，建立可逐层进入的学术导航。
- 建立两部原著中定义、定理与定律的搜索索引。
- 统一“信息原理”“信息的数学原理”“认知”“完备建模”等中英文术语。
- 全站公式改为语义化 MathML，并修正 OCR 造成的符号、上下标和互信息公式错误。
- 恢复五大研究模块、团队页和三部李昂生著作入口。
- 修复锚点跳转锁定滚动、移动端导航、Safari 箭头和中文孤字换行等问题。

## 工程改进

- 新增 38 个公开路由的可重复静态渲染脚本。
- 新增 GitHub Actions release checks。
- 补齐体系结构、内容维护、部署回滚和发布清单文档。
- 清理未使用的 starter 页面依赖，并将项目元数据更新为 `mousuan-ai@0.9.0`。
- 将内部审稿页面和图片迁出 Git 当前版本树，并保留在本地忽略目录中。

## 验证标准

- 生产构建成功。
- 15 项服务端渲染与内容一致性测试通过。
- 38 个公开路由成功生成静态 HTML。
- 静态发布目录不包含 `audit-redesign` 或内部手稿图片。

## 已知边界

- 当前 IP 加端口地址仅用于海外审阅，不是最终正式域名。
- 中国大陆正式上线仍需完成域名、HTTPS、ICP 备案和上线验收。
- 早期公开提交和旧标签中曾包含内部审稿资料；若需要从公开 Git 历史中彻底移除，必须另行评估并执行受控的历史重写。
