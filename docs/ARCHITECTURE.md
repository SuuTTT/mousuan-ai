# MouSuanAI 体系结构

## 1. 内容层次

网站以四个科学问题作为入口，以“1 + 3 + 1 + 5”作为主体结构。

```text
四个科学问题
  └─ 一个中心：信息及信息世界的数学原理
       ├─ 三个定义
       │    ├─ 智能 = 信息
       │    ├─ 智能 = 谋算
       │    └─ 智能 = 智 + 能
       ├─ 一个模型：孙子模型
       └─ 五个研究模块
            ├─ 科学原理
            ├─ 机器智能技术
            ├─ 孙子模型
            ├─ 认知与设计
            └─ 谋算智能机
```

首页只承担“提出问题、给出答案、进入下一层”的任务。定义、命题、定律和论证放在独立主题页、概念页和原理页；正式编号和原文入口集中在定理索引与著作页。

## 2. 路由职责

| 路由 | 职责 |
| --- | --- |
| `/` | 四个问题、信息中心、三个定义、孙子模型与五大模块入口 |
| `/themes/*` | 四个问题及孙子模型的独立主题说明 |
| `/concepts/*` | 单一概念的对象、关系和理论位置 |
| `/principles/*` | 数学原理、信息科学原理和策略原理 |
| `/modules/*` | 五大研究模块的总览与分支入口 |
| `/applications/*` | 具体研究方向与应用场景 |
| `/theorems` | 两部原著中的定义、定理和定律检索 |
| `/wiki/terminology` | 中英文规范术语表 |
| `/books` | 三部主要著作与站内引用锚点 |
| `/team` | 团队贡献、成员与研究计划 |

## 3. 代码结构

- `app/`：页面、路由、全局样式与共享组件。
- `app/MathText.tsx`：把受支持的公式表达转换为语义化 MathML。
- `app/theorems/book-index.json`：原著编号条目的检索数据。
- `public/`：公开图片、专著资料和社交分享图。
- `internal-audit/audit-redesign/`：本地忽略的内部审稿资料，仅用于核验，不进入 Git 当前版本树或公开静态发布目录。
- `scripts/`：索引提取、文档生成和静态发布脚本。
- `tests/`：服务端渲染、术语、公式、引用、路由和安全滚动测试。

## 4. 渲染与发布

项目使用 vinext 构建 React Server Components，并保留 Cloudflare Worker 兼容入口。当前审阅服务器使用静态发布目录：

1. `npm run build` 生成 `dist/client` 与 `dist/server`。
2. `npm run render:static` 调用构建后的 Worker，为 38 个公开路由生成 HTML。
3. 生成结果位于 `.release/site`，只包含公开页面和资源。
4. 服务器以不可变 release 目录保存每个版本，再由 `current` 符号链接切换当前版本。

新增公开路由时，必须同步更新 `scripts/render-static.mjs` 中的路由清单和渲染测试。

## 5. 导航约束

- 所有子页必须提供“研究主页”入口。
- 跨页锚点通过 `SafeAnchorNavigation` 处理，避免跳转后锁定滚动。
- 文档内部原生片段不应被 JavaScript 改写。
- 中文与英文页面使用相同的知识层次和规范术语，不得仅作逐字直译。
