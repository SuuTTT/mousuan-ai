# 内容维护规范

## 1. 术语优先级

网站术语以原著和经确认的术语表为准。当前核心用语包括：

| 中文 | 英文 |
| --- | --- |
| 信息原理 | Information principles |
| 信息的数学原理 | Mathematical principles of information |
| 信息世界的数学原理 | Mathematical principles of the information world |
| 认知 | Cognition / Cognitive |
| 现实世界的完备建模 | Completely modeling the real world |
| 智能论题 | Intelligence thesis |
| 智能的策略原理 | Strategy principle of intelligence |

“数学原理”用于信息世界；物质与信息共同参与的战争理论使用“科学原理”。网站自有文案使用“认知”，不得将其改回“认识”；原著引文保持原文。

## 2. 来源与引用

1. 同一命题在多部著作中出现时，优先链接最早的正式来源。
2. 基本定律优先引用《人工智能科学——智能的数学原理》（2024）。
3. 谋算策略、孙子五大定律等后续内容可引用《孙子兵法的人工智能原理》（2026）。
4. 首页不放密集引用；引用进入主题页、原理页、索引页和著作页。
5. 编号、页码、公式和原文必须以本地原著为准，不依据手稿猜测。

## 3. 写作方式

- 面向研究者写作，不出现“按要求”“这一页恢复”“点击下列分支”等开发提示或 prompt 回复。
- 首页先给出答案，细节通过第二、第三层页面展开。
- 定义、命题和定律采用陈述式语言；解释文字不得降低原命题的数学强度。
- 团队成员介绍不添加教授、博士生等分组或职称前缀，以学术贡献和研究方向为主。
- 中文标题避免孤字换行；英文术语注意完整词组，不用手工断词。

## 4. 数学表达

- 公式使用 `MathText` 或语义化 MathML，不以普通正文模拟上下标、求和号和分式。
- 中文说明使用全站无衬线字体；变量、数字和运算符使用数学字体。
- 新增公式必须在中文和英文状态下检查，并为关键公式提供可访问的 `aria-label`。
- OCR 结果只能作为录入线索，必须对照原书校正符号、下标、括号和编号。

## 5. 内部资料边界

18 页结构手稿和审稿页面是内部知识设计资料：

- 不在网站导航、搜索或页面正文中出现。
- 不复制到 `.release/site` 或生产服务器公开目录。
- 若 GitHub 仓库需要公开，应先将其移出公开分支或迁入独立私有资料库。
- 任何公开 release 都应检查归档包内不存在 `audit-redesign`、页码图片或内部审阅文字。

## 6. 内容变更检查

每次修改理论内容后应同时检查：

1. 首页中英文文案。
2. 对应主题、概念和原理页面。
3. `/wiki/terminology` 术语表。
4. `/theorems` 的来源、编号和搜索词。
5. `/books` 的引用锚点。
6. `CHANGELOG.md` 与相关测试。
